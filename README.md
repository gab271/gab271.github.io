# gab271.github.io

Portfolio personal de **Gabriel Medina**, desarrollador de software junior.

🔗 **https://gab271.github.io**

Hecho con React, Vite y Tailwind CSS. Se despliega automáticamente en GitHub Pages con cada push a `main` (ver `.github/workflows/deploy.yml`).

## Desarrollo

```bash
npm install
npm run dev
```

Todo el contenido (proyectos, stack, trayectoria) está en `src/data.js`.
